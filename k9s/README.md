# K9s Skins

[K9s](https://k9scli.io/) Catppuccin Mocha skin for the Kubernetes CLI dashboard.

## Setup

Symlink the skins directory:

```bash
ln -sf ~/neko/k9s/skins ~/Library/Application\ Support/k9s/skins
```

## Tips

- To switch skins, set `k9s.ui.skin` in `~/Library/Application Support/k9s/config.yaml` to the skin name (e.g. `catppuccin-mocha`).

## Dependencies

- [K9s](https://k9scli.io/) — Kubernetes CLI dashboard
